# Security Policy

## Scope

This is a personal learning/portfolio repository. It contains **no production
systems and no real user data** — all datasets are synthetically generated
(see `shared/data-generators/`, which use a fixed `SEED = 42`). Any names,
email addresses, or order records visible in code, query output, or
screenshots are fabricated.

## Reporting a vulnerability

If you find a security issue — a leaked credential, an insecure IAM pattern,
or anything else worth flagging — please **open a GitHub issue** describing
it, or contact me through my GitHub profile.

Since nothing here is production infrastructure, there is no embargo process
and no need for private disclosure. Public issues are fine and preferred, so
others can learn from the finding.

## Known deliberate weaknesses

Some things in this repository are intentionally imperfect, and are documented
as such rather than hidden:

- **Seeded data-quality issues.** The generators deliberately inject NULL
  emails, NULL `supplier_id` values, negative quantities, and ~1% duplicate
  `orders` rows. These are test fixtures for the dbt/Dataplex quality checks,
  not bugs. See `shared/data-generators/generate_peakcart_data.py`.
- **Documented trade-offs.** Each project's `NOTES.md` records design
  compromises made for scope reasons, including the serving gap during
  model retraining in project-05 and the IaC coverage gaps in project-03.

## Credential handling in this repository

No credentials are committed. Verified practices:

- Secrets are generated by Terraform (`random_password`) and stored in Google
  Secret Manager; jobs fetch them at runtime rather than receiving them as
  arguments.
- Database passwords are read from environment variables, never inlined.
- `.gitignore` excludes `service-account*.json`, `*-key.json`,
  `*-credentials.json`, `.env`, `*.tfstate`, and all generated data output.
- dbt profiles are provided as `profiles.yml.example` only; the real
  `profiles.yml` is never committed with credentials.

If you believe you've found a credential in this repository or its history,
please report it — that would be a genuine bug.
